Repairs: messages to customers, job tickets with a QR code, and invoices.

**Updating:** update the App and the Home Inventory integration (HACS). No database changes.

## New
- **Customer messages:** in the integration's options, pick a notify action that reaches customers (SMS or email) and which job changes to send. Home Assistant events still carry no customer details.
- **Job ticket:** a tag for the machine with a QR code that opens the job.
- **Invoice:** the work order as an invoice with your business name and details (Settings → Preferences). Stock parts used are priced automatically.
