Tell Home Inventory when you've moved something.

**Updating:** update the App and the Home Inventory integration (HACS). No database changes. Then:
1. **Assist:** copy the new `deploy/assist/custom_sentences/en/home_inventory.yaml` to `custom_sentences/en/` in your Home Assistant configuration folder, and reload conversation (or restart).
2. **Alexa:** developer console → your skill → **Build → Interaction Model → JSON Editor**: paste the new `deploy/alexa/interaction-model.json`, **Save**, **Build skill**. **Code** tab: replace `lambda_function.py` with the new `deploy/alexa/lambda_function.py`, put your `HA_URL`, `HA_TOKEN` and `SKILL_ID` back near the top, **Save**, **Deploy**.

## New
- **"Alexa, tell Home Inventory that I've moved the engine oil to small engine repair"** (or "…to container number 5"). With Assist: "I've moved the engine oil to…", "I put the drill in the garage", "The hedge trimmer is now in the shed".
  - Item and place names don't have to be exact; containers can be named by number.
  - A clear match is moved and confirmed. Unclear: "Did you mean Small Engine Repair, in Shed?" (yes or no), or "Which place: …?" when several fit. It also asks which item when several fit.
  - The move is permanent and is recorded in Activity history; to move it back, say so again or use Move on the item page.
