A printed contents checklist for a box, read back from photos. No database changes. Update the App (the integration only changes its version number).

## New
- **Printed checklist** on each box: every item with its photo, and boxes to tick (back here, dispose, missing, move to, new count).
- **Read completed checklist**: photograph or scan the filled-in pages. The AI reads the marks and you review every row before anything changes, then apply moves, disposals, missing items and counts together, saved as a check of the box.
- **Fill in by hand** when AI isn't set up.
