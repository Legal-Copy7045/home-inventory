What needs taking care of, in one place, and checking that the records match what's really on the shelf.

**Updating:** update the App and the Home Inventory integration (HACS) for the new **Needs attention** sensor. The App runs one automatic, additive database migration (inventory checks, and when each item was last seen). Existing items start as "never checked"; nothing else changes.

## New
- **Needs attention**: overdue and upcoming maintenance, missing parts, low stock, things out, repairs, results to review and more, most urgent first, each linking to where to act.
- **Check inventory**: tick, scan, recount or mark missing in a place, box or category; things found from elsewhere can be moved here. History of every check, and what's changed since the last one.
- **Last checked** on every item.
