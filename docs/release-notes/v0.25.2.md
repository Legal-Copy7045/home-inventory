## Fixed
- Adding a location from inside another place (Add sub-location) looked the same as adding a top-level one, so a new room could end up inside e.g. Basement. The form now says where it goes ("New location inside Basement" or "New top-level location") and can switch to the top level.
- Moving a location to the top level is labelled **Move it to the top level**.
- Top-level places in the Locations tree are separated by a line.

To fix a room that ended up in the wrong place: open it → **Move** → **Move it to the top level**.
