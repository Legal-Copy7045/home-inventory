Undo, sharper photos on powerful machines, and Alexa that copes with real answers.

**Updating:** update the App and the Home Inventory integration (HACS). No database changes. If you use the Alexa skill, update its interaction model and forwarder code (below).

## New
- **Undo** after using or adding one, moving, changing status, deleting an item or an empty location, and moving several items.
- **Photo detail** in the App configuration: `high` for a powerful machine or VM keeps larger photos, sharper panoramas and cut-outs, and gives the AI more detail.

## Changed
- *Add item* has one **Add photos** button (camera, library or files).
- Recent activity moved off Home; it's under **Activity history** in the menu.
- Voice and search treat numbers as digits or words alike ("0 turn" = "zero turn").
- Alexa: you can answer "which one?" with just a name, and a misunderstood request ends the skill instead of trapping you in it.

## Alexa skill update
1. Developer console → your skill → **Build → Interaction Model → JSON Editor**: paste the new `deploy/alexa/interaction-model.json` (it adds the `HomeInventoryAnswer` intent and a `HomeInventoryThing` slot type), **Save**, **Build skill**.
2. **Code** tab: replace `lambda_function.py` with the new `deploy/alexa/lambda_function.py`, then put your `HA_URL`, `HA_TOKEN` and `SKILL_ID` back near the top (Alexa-hosted), **Save**, **Deploy**. With your own AWS Lambda, paste the whole file; the settings stay in its environment variables.
