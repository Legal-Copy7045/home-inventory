**Updating:** update the App. No database changes.

## Changed
- **Add item** starts with name, category, quantity and where it is. The rest is one tap away under *Make, model, barcode & more details* (it opens by itself when AI, a barcode or a link fills it in).
- **New items start where the last one went.** Tap the place to change it.
- **Shorter item pages.** A small **Add photo** button when there's no photo, and one *Add:* row for documents, related items, restock alerts and NFC tags until you use them.
- **Shelves show what's on them** ("1 box · 4 things"), counting boxes and smaller places too.
- **Lists inside a box or shelf** show each item's category rather than repeating the place.
- **Home** shows the last 5 changes.
