Fixes App updates failing with "The update could not be started: [object Object]".

**Updating:** update the App as usual. This update already downloads the ready-made image.

## Fixed
- Home Assistant was building the App on your own machine at every update, which could fail. From this version it downloads the ready-made image published with each release instead, which is quicker and more reliable.

## If an update still fails
1. Wait a few minutes after a new release appears: its image takes about three minutes to publish. Then go to Settings → Apps → App store → ⋮ → **Check for updates**.
2. Open Home Inventory and update again.
3. If it still fails, Settings → System → Logs → **Supervisor** shows the reason. Your inventory data isn't affected either way.
