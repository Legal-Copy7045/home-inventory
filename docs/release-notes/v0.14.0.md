Better photo cut-outs, scanned PDFs, tidier labels, container numbering and smarter location search.

**Updating:** update the App (and the integration in HACS to keep versions together). No database changes.

## Fixed
- **Photo inventory cut-outs** now show the right thing. The AI reports positions in the format vision models are best at. If a cut-out is still wrong, untick **Photo** on that row in the review and it's saved without one.

## New
- **Scanned PDFs are read.** Manuals are read page by page (the first 12 pages, or the ones you type in **Pages to read**, e.g. 18-26), and scanned receipts and warranties from their first pages.
- **Read the manual** is always there for items, even before maintenance tracking is on, and on manual documents themselves.
- **Labels:**
  - The number is printed large, then the title, description and contents, with the location at the foot.
  - Long titles and locations wrap between words instead of being cut off or split.
- **Container numbers:** new containers get the next free number, and you're warned if you choose one that's already used.
- **Location search by words:** type words in any order, such as "shed right front shelf", to find places anywhere in the hierarchy.
