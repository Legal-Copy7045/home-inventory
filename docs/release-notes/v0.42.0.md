Security and privacy fixes from the first full regression audit. **Update the App and the integration.** Container/Core: update `docker-compose.yaml` too.

## Security
- Customer equipment is no longer named in the "maintenance due" event and notification, in automatic shopping-list notes, or in product history shown to read-only users.
- Only product barcodes are looked up online, and a failed lookup no longer logs the Barcode Lookup API key.
- `admin_users` / `read_only_users` match usernames or user ids, not display names. Home Assistant's answer about administrators wins over a request's claim.
- The integration checks the App address before every request and connects only to the checked address. Numeric IPv4 spellings are recognised.
- Photos and documents aren't cached by browsers. Wide-area photo uploads accept the same formats as other uploads. Link imports check NAT64 addresses.
- Container/Core: the API port is published on `127.0.0.1` by default (`HINV_BIND_IP` for a LAN address), the container drops extra privileges, and the data folder is private to the App.

## Repository
- The privacy guard checks every new commit and media metadata. Actions are pinned to commits, with Dependabot.
