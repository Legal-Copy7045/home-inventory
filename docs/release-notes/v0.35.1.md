Fixes the Alexa skill's interaction model, which the Alexa console refused to build.

**Updating:** in the Alexa developer console, paste the new `deploy/alexa/interaction-model.json` (Build → Interaction Model → JSON Editor → Save → Build skill), and replace the skill's code with the new `deploy/alexa/lambda_function.py` (put your HA_URL, HA_TOKEN and SKILL_ID back). The App and the integration only change their version numbers.

## Fixed
- "Slot … cannot reference more than one slot type": every slot name now has one type across the skill.
- Item, equipment and job names are free-text search slots, so anything in your inventory is understood, not only the example names.
- The forwarder passes the moved thing to Home Assistant under the name it expects.
