Security hardening.

**Updating:** update the App and the Home Inventory integration (HACS). No database changes.

## Changed
- Inventory data is never stored by browsers or proxies, so it doesn't linger on a shared phone or computer.
- Other websites can't embed Home Inventory's pages, photos or data.
- The internal API documentation is hidden unless you're debugging.
- The QR label address in Settings only accepts a web address.
- Very large photos in a wide-area photo inventory can't run the App out of memory.
- Sidebar panel on Home Assistant Container/Core installs: stricter cross-site protection.

## Check your Home Assistant
Home Assistant is the part that faces the internet, so it's what protects Home Inventory. See "Residual risks and recommendations" in `docs/security.md`: remote access through Home Assistant Cloud or a VPN, multi-factor authentication for every user, login attempt limits, Protection mode on for Apps, and `default_role: read_only` for Home Inventory if you share Home Assistant with guests.
