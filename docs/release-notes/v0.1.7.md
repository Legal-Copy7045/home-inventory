Home Inventory is a household inventory that lives inside Home Assistant. Photograph things and let AI suggest what they are, label boxes with QR codes, scan barcodes, and find anything by asking "where are my axle stands?".

This is the first public release. If you used an earlier build, update as normal: your data is kept.

## Highlights

- **Quick photos**: open a box, tap *Quick photos* and photograph item after item. Each one is saved into that box straight away, and you add the details later from **To finish** with *Save & next*. If AI is set up, a suggested name and category are already filled in.
- **AI identification using Home Assistant's own AI** (for example the Google Gemini integration, free tier). No extra API key is needed. Every suggestion is reviewed by you before it's saved.
- **QR labels that open on your phone**: printable Avery A4/Letter sheets (5160/5163/5164 and the WeatherProof 5520/5523/5524), or label printers. Scanning a label with the phone camera opens that box or location in Home Assistant.
- **Natural-language search** answered only from your own data, so locations and quantities are never invented.
- Quantities and expiry dates, low-stock alerts, loans and temporary moves, visual maps, Excel import of your location tree, import from a product web link, family roles, full history and trash.
- Home Assistant sensors, actions and automation events via the companion integration.

## Install

1. Back up Home Assistant first.
2. Add the App repository: Settings → Apps → App store → ⋮ → Repositories → `https://github.com/Legal-Copy7045/home-inventory`, or use the button in the README.
3. Install **Home Inventory**, start it and open **Inventory** in the sidebar.
4. Optional: install the companion integration through HACS (custom repository, type *Integration*).
