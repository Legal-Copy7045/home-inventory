Security hardening of the companion integration. **Update the integration**; the App only changes its version number.

## Changed
- The integration only talks to the Home Inventory App on this machine or your own network. Any other address is refused when you set it up, and again before every request, so your Home Assistant user details and the App token are never sent anywhere else. Existing setups keep working.
