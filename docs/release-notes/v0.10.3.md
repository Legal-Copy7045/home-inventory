**Updating:** update the integration in HACS (and the App, to keep versions together), then restart Home Assistant. No database changes and nothing to change in Alexa or Assist.

## Changed
- Plural names now get "are": *"Wood screws are in Basement, Server Shelf Left, Top Shelf."*, *"Pliers are lent to Sam."*
- Singular names keep "is": "Axle stand is…", "Box of screws is…", "Siphon pump with hose and funnel is…".
- It goes by the name, not how many you have, so a single "Axle stands" record still says "are".
