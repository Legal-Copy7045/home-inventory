Labels in three styles with room colours, and a put-away route after a job.

**Updating:** update the App. No database changes. The integration only changes its version number.

## New
- **Put-away route:** Scan → Collect gathers what you used; the Put-away Route takes you round each place in turn, room by room.
- **Label styles:** Large print, and Small drawer (with the Avery L7651 65-per-sheet template).
- **Colour band per room:** a coloured strip with the room's name down each label's edge.
