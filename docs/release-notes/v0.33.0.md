Ask Home Assistant about maintenance: what's due (overall or for one machine), what parts the next service needs, when a job was last done, and what needs attention.

**Updating:** update the App and the Home Inventory integration (HACS), then copy `deploy/assist/custom_sentences/en/home_inventory.yaml` to your Home Assistant `custom_sentences/en/` folder again and reload conversation. For Alexa, paste the new interaction model and forwarder code (see *Updating the skill* in `docs/voice.md`). No database changes.

## New
- "Tell me what upcoming maintenance I need to perform [on the Toro lawn mower]", with overdue / today / this week / this month.
- "What parts do I need for the next mower service?", "Do I have the parts I need to service the snowblower?"
- "When did I last change the oil in the mower?", "What equipment needs attention?", "What maintenance have I completed recently?"
- Asks which one when a name fits several machines.

## Fixed
- "The hedge trimmer is now in the shed" (Assist) now moves it.
