AI that stays inside your plan's limits, a tidier menu, and stepping through items.

**Updating:** update the App. No database changes. If you use Gemini and set `ai_model` to a retired 2.x model, clear it to use the new default `gemini-flash-lite-latest`.

## New
- **AI rate limits** (App configuration): requests per minute, tokens per minute and requests per day, defaulting to Gemini's free tier (15 / 250,000 / 500). Requests queue so the limits are never exceeded; background work finishes over time. A "too many requests" answer pauses AI for `ai_retry_cooldown` seconds (default 60) and retries. **Settings → AI** shows usage.
- **Maintenance plan** under Reports: equipment, jobs, intervals, last service and parts, printable.
- **Previous / Next** on item pages.

## Changed
- The menu is grouped into Inventory, Care, Reports and Admin; *To sort & finish* and *Maintenance & Repairs* each combine pages as tabs.
- Inventory report item names link to the item.
- Location labels show the location path in bold.
- Gemini's default model is `gemini-flash-lite-latest`.

## Fixed
- "Where is the lawnmower" found the engine oil instead of the *Lawn mower*.
- Re-scanning a shelf duplicated boxes and items already recorded there; boxes can now redo wrong cut-outs.
