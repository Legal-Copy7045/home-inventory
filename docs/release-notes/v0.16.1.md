Shelf labels that show what goes there, with arrows pointing the way.

**Updating:** update the App. No database changes.

## New
- **Arrows on labels.** Add a big arrow (↑ ↓ ← → or a diagonal) to any shelf or container label, pointing to where it is, for example from the end of a rack up to the top shelf. Choose one for all selected labels, or per label.
- **Shelf labels list their contents.** A shelf, rack or cabinet label lists the shelves or drawers within it, the boxes and the loose items kept there, so anyone putting things away knows where they go. The QR code opens the current list. It's ticked by default when you print from a shelf (QR icon → **Print label**).
