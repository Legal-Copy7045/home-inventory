Identify everything on a shelf from one photo, and work with many items at once.

**Before updating:** take a Home Assistant backup. This release includes a small database change, applied automatically after a snapshot. If you skipped earlier releases, see the [v0.8.0](https://github.com/Legal-Copy7045/home-inventory/blob/main/docs/release-notes/v0.8.0.md) and [v0.7.1](https://github.com/Legal-Copy7045/home-inventory/blob/main/docs/release-notes/v0.7.1.md) notes too; v0.7.1 has security fixes.

## New

### Photo inventory for shelves (needs an AI provider)
- Open a shelf, racking bay, bench or wall (any location) and tap **Photo inventory**. Take one photo.
- The AI lists every kind of item it can see, with quantities and where each one is ("top shelf, left").
- Check it all before anything is saved:
  - edit names and quantities;
  - tap **Details** for category, maker, model and notes;
  - remove wrong guesses and add anything it missed.
- Confirmed items become loose items on that shelf, with the photo attached.
- Photographing the shelf again later updates what's there instead of duplicating it.
- Container photo inventory gets the same editing.

### Select several items
- On **Items**, tap **Select**, tick items (or **Select all**), then **Move**, **Edit** or **Delete** them together.
- **Edit** changes category, maker, shop, purchase date or status, and only the fields you fill in.
- Each action applies to every selected item or to none of them. Deleted items can still be restored.

### Sort by location
- **Items → Sort: Location** groups items under the shelf, box or room they're in.
