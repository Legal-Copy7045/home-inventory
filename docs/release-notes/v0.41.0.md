Consumables by designation, all the manuals read in order, and an editable list of what a model takes. No database changes; update the App (the integration only changes its version number).

## New
- **Designation, not brand**: 10W-30 oil counts as 10W-30 from any maker (never as 10W-40), and a "Spark plug" standard counts any spark plug. The type and grade are recognised from the name, and you can correct them.
- **Read the manual** reads all the machine's manuals in order, and an engine manual wins the engine jobs and parts.
- **Parts this model takes** can be edited, removed and added.

## Changed
- Reading another manual replaces the same role's part from a lower-ranked manual instead of adding another one.
