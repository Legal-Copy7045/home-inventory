AI now reads the documents you add to an item and offers to fill in its details.

**Updating:** update the App and the integration in HACS. The database upgrade adds one table.

## New
- **Documents are read automatically.** Add a receipt, warranty card, invoice, order email, manual or certificate to an item, as a PDF or a photo. A few seconds later it shows what it is, for example *Receipt – 6 things to fill in*. Tap **Review**:
  - you're offered the purchase date, price, shop, warranty start and end, make, model and serial number, whichever are printed;
  - empty fields are ticked, and anything that would replace what you already have is shown side by side and left unticked;
  - you can correct a value before saving, and the document is filed under the right type with a name such as "Lowe's receipt".
- If you're not sure what a document is, choose *Not sure – let AI work it out* when adding it.
- **Read with AI** reads documents you added before this version.

## Notes
- Values are copied only from what's printed, never guessed.
- A document about a different product isn't used to fill anything in.
- Scanned PDFs have no text to read; add a photo of the document instead.
- Needs an AI provider configured in the App. Without one, documents are stored as before.
