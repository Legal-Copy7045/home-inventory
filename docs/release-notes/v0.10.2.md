Clearer voice answers for things in boxes.

**Updating:** update the App and the integration (HACS), then restart Home Assistant. No database changes, and nothing to change in your Alexa skill or Assist sentences.

## Changed
- Voice answers now name the box first, then where the box is: *"Kink Control Plus Water Hose 50ft is in Plastic tote number 1, labelled Hoses, located in Shed, Rear Right Shelving, Middle Shelf."*
- Boxes inside boxes are named innermost first ("in Fittings tin, inside Plastic tote number 1…").
- The box's **type** is used when the container has one (container → Edit → Type, e.g. "Plastic tote"); otherwise its name and number ("Hoses number 1").
